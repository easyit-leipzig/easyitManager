# Administration

Das ausführliche HTML-Handbuch befindet sich unter `help/admin-handbook.html`.

Enthalten sind:

- Installation und Pflege von `main_settings`
- Datentypen und Einstellungsgruppen
- Rechte, Ansichten und Funktionsabhängigkeiten
- Ableitung der `init.json`
- Rollenprofile, Sicherung, Validierung und Fehlerdiagnose
- Sicherheitsanforderungen für eine spätere PHP-/API-Anbindung

SQL: `sql/main_settings.sql`

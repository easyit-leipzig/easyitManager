# Monatsansicht

Die Monatsansicht dient ausschließlich der Darstellung aller Termine.

- sieben Spalten von Montag bis Sonntag
- chronologische Anzeige aller Termine je Kalendertag
- Anzeige von Beginn, Ende, Thema und Beschreibung
- inaktive Termine werden abgeschwächt dargestellt
- Tage außerhalb des gewählten Monats werden zurückhaltend angezeigt
- kein Drag-and-drop
- keine Terminbearbeitung
- keine Slot-Blockierung
- Navigation monatsweise über die Pfeiltasten

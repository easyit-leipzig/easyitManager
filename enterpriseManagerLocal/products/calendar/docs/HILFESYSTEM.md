# HTML/CSS-Hilfesystem

- `help/index.html`: Gesamtübersicht
- `help/day.html`: Tagesansicht
- `help/week.html`: Wochenansicht
- `help/month.html`: Monatsansicht
- `help/help.css`: gemeinsames Layout

Der Button **Hilfe** öffnet ein modales Fenster und lädt automatisch die Datei der aktiven Kalenderansicht. Das Hilfepaket kann auch unabhängig vom Kalender direkt im Browser geöffnet werden.

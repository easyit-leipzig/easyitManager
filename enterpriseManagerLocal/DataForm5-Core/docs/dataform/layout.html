DataForm 5 – Layout

Auf dieser Seite wird die visuelle Struktur einer DataForm aufgebaut. Layoutobjekte strukturieren die Oberfläche, ohne das zugrunde liegende Datenmodell zu verändern.

Inhalt 1. Zweck 2. Zusammenhang 3. Schritt für Schritt 4. Elementtypen 5. Layoutstruktur 6. Beispiele 7. Typische Fehler 8. Workflow 9. Expertenmodus 10. Help-Integration

1. Zweck der Layout-Seite

Mit Layoutobjekten strukturieren Sie die Oberfläche einer DataForm. Sie können Seiten, Gruppen und Registergruppen anlegen und damit Felder später übersichtlich anordnen. Das Layout verändert nicht die Tabellen-, Feld- oder Relationsdefinitionen.

Wichtig: Die Layout-Seite verändert die Darstellung und Strukturierung einer DataForm, nicht das Datenmodell.

2. Layout im Zusammenhang

Help-IDBereichAufgabe
dataform.settings Einstellungen Standardansicht, Dialoggröße und AddCSS werden in den Einstellungen gepflegt.
dataform.form Formular Feldbreiten und die konkrete Formularanordnung werden im Formular-Designer bearbeitet.
dataform.preview Realvorschau Das fertige Layout wird mit echten Datensätzen in der Realvorschau geprüft.

3. Schritt-für-Schritt-Assistent

  1. Elementtyp auswählen
    Wählen Sie unter „Elementtyp“ das gewünschte Layoutobjekt aus. Für den ersten Aufbau ist normalerweise eine Seite ein sinnvoller Einstieg.
  2. Titel vergeben
    Tragen Sie einen aussagekräftigen Titel ein, zum Beispiel „Persönliche Daten“, „Adresse“ oder „Zusatzinformationen“.
  3. Layoutobjekt hinzufügen
    Betätigen Sie den zentral registrierten Hinzufügen-Button. Das neue Layoutobjekt erscheint anschließend in der Layoutstruktur.
  4. Struktur aufbauen
    Ergänzen Sie weitere Seiten, Gruppen oder Registergruppen und ordnen Sie diese hierarchisch entsprechend der gewünschten Benutzeroberfläche an.
  5. Formularfelder zuordnen
    Wechseln Sie anschließend in den Formular-Designer und ordnen Sie die eigentlichen DataForm-Felder den vorgesehenen Layoutbereichen zu.
  6. Darstellung prüfen
    Kontrollieren Sie das Ergebnis in der Realvorschau mit echten Datensätzen. Prüfen Sie insbesondere Reihenfolge, Gruppierung, Feldbreiten und Bedienbarkeit.

5. Layoutstruktur

Die Layoutstruktur zeigt alle bereits angelegten Layoutobjekte in ihrer hierarchischen Anordnung. Hier wird sichtbar, welche Bereiche über- oder untergeordnet sind.

Beginnen Sie mit einer Seite, Gruppe oder Registergruppe.

7. Typische Fehler

ProblemLösung
Es wurden noch keine Layoutobjekte angelegt. Wählen Sie einen Elementtyp, vergeben Sie einen Titel und fügen Sie das erste Layoutobjekt hinzu.
Felder werden im Layout-Designer gesucht. Der Layout-Designer erzeugt nur Strukturcontainer. Die Feldanordnung erfolgt anschließend im Formular-Designer.
Die Darstellung in der Laufzeit stimmt nicht mit der Erwartung überein. Prüfen Sie Standardansicht und Dialoggröße in den Einstellungen, die Feldanordnung im Formular-Designer und anschließend die Realvorschau.
Layout und Datenstruktur werden miteinander verwechselt. Änderungen an Tabellen, Feldern oder Relationen werden nicht hier, sondern in den dafür vorgesehenen Datenmodell- beziehungsweise Recordset-Bereichen vorgenommen.

8. Empfohlener Workflow

  1. Datenmodell und Recordsets definieren.
  2. DataForm-Grundeinstellungen festlegen.
  3. Layoutstruktur erstellen.
  4. Formularfelder im Formular-Designer zuordnen.
  5. Feldbreiten und Reihenfolge optimieren.
  6. Realvorschau mit echten Datensätzen prüfen.
  7. Bei Bedarf Layout nachjustieren.

9. Expertenmodus

Layoutobjekte gehören ausschließlich zur Präsentations- und Strukturierungsebene einer DataForm. Sie dürfen keine Tabellen-, Feld-, Schlüssel- oder Relationsdefinitionen verändern. Die fachlichen Daten bleiben im Recordset beziehungsweise Datenmodell verankert. Das Layout beschreibt lediglich, wie diese Datenbereiche in der Oberfläche organisiert und später im Formular-Designer mit konkreten Feldern belegt werden.

  • Layoutdefinition und Datenmodell strikt trennen.
  • Eine Layoutänderung darf keine Datenmigration auslösen.
  • Feldzuordnungen werden im Formular-Designer gepflegt, nicht im Layout-Designer.
  • Standardansicht, Dialoggröße und AddCSS gehören in die DataForm-Einstellungen.
  • Die Realvorschau dient der Prüfung mit tatsächlichen Datensätzen.
  • Aktionsbuttons verwenden die zentrale Button-Registry; lokale farbige oder verlaufende CSS-Buttons sind nicht vorgesehen.
  • Titel und aria-label von registrierten Aktionsbuttons stammen aus der zentralen Button-Registry.
  • Leere Layoutobjekte sind technisch möglich, sollten aber nur bewusst als vorbereitete Struktur verwendet werden.

10. Aufruf über das zentrale Help-System

Die Layout-Hilfe wird nicht über einen hart codierten Dateipfad aufgerufen, sondern über die zentrale Help-ID dataform.layout.

Permanentes Hilfefenster

DataFormHelp.show(
    "dataform.layout",
    "#dataform-help-panel"
);

Vollständige Dokumentation

DataFormHelp.open(
    "dataform.layout"
);

Kontextwechsel zur Layout-Seite

document.addEventListener(
    "dataform:pagechange",
    event => {
        if (event.detail?.page === "layout") {
            DataFormHelp.show(
                "dataform.layout",
                "#dataform-help-panel"
            );
        }
    }
);

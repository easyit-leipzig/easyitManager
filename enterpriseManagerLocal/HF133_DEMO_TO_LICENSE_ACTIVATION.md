# HF133 – Demo → Lizenzaktivierung vor Surface-Gate

Der Kundenlogin trennt ab HF133 drei Schritte sauber:

1. Konto authentifizieren.
2. Eine inzwischen vergebene aktive Lizenz erkennen und an die lokale Installation binden.
3. Erst danach die Domain-/IP-Policy für produktive Funktionen auswerten.

Eine fehlende Domainfreigabe verhindert damit nicht mehr die Lizenzübernahme. Der Manager bleibt in diesem Fall auf Dashboard und „Mein Konto“ beschränkt. Dort kann ein berechtigter Kundenadministrator die fehlende Domain/IP ergänzen. Produktive Projekte, DataForms, Designer, Export, API und weitere lizenzierte Ressourcen bleiben bis zur erfolgreichen Surface-Prüfung gesperrt.

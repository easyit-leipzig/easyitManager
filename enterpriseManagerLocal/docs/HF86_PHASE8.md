# HF86 Phase 8 – Herkunftsfreigaben gegen Selbstaussperrung

Die Self-Service-Pflege unter **Mein Konto** schützt jetzt verpflichtende Herkunftsregeln.

- Die letzte aktive Domain kann bei verpflichtender Domainprüfung nicht entfernt werden.
- Das letzte aktive IP/CIDR-Netz kann bei verpflichtender IP-Prüfung nicht entfernt werden.
- Zusätzlich kann die aktuell verwendete Domain bzw. IP-Freigabe nicht entfernt werden, wenn keine verbleibende Regel den aktuellen Enterprise-Zugriff weiterhin erlaubt.
- Der Benutzer erhält dafür eine konkrete Fehlermeldung und kann zuerst eine weitere passende Freigabe hinzufügen.

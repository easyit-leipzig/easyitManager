# HF96 – Projektanlage repariert

- Produktliste wird nicht mehr nach dem Laden versehentlich geleert.
- Produkt/Projektart ist auswählbar.
- Datenbank-/Speichertyp ist je Projekt auswählbar.
- Nicht verfügbare PDO-Treiber werden ausgeblendet.
- Der gewählte Treiber wird für die Projekt-Provisionierung verwendet.
- Verbindungseinstellungen werden passend zur Auswahl angezeigt.
- PostgreSQL zeigt zusätzlich das konfigurierte Schema.
- PHP-Syntaxprüfung `app/projects/create.php`: PASS.

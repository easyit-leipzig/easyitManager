# Enterprise-Manager – frische lokale Installation

Ziel: `D:\xampp\htdocs\enterpriseManager`

1. Ordner frisch entpacken.
2. `config/licensing.local.example.php` erst nach erfolgreicher Einrichtung des Lizenzservers nach `config/licensing.php` kopieren und Public Key eintragen.
3. `http://localhost/enterpriseManager/setup.php` aufrufen und Administrationsspeicher einrichten.
4. Lokalen Admin/Superadmin anlegen.
5. Kundenlogin erfolgt über `http://localhost/enterpriseManager/login.php`.

Keine lokale Lizenzidentität, Session oder Kundendaten sind im ZIP enthalten.

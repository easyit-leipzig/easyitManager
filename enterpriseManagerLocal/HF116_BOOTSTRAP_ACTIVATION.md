# HF116 – Bootstrap-Aktivierung

Der Enterprise-Manager kann mit einem einmaligen Bootstrap-Aktivierungsschlüssel registriert werden, den der Lizenzserver-Superadmin ohne Kundenkonto erzeugt. Der Manager sendet bei der Kundenanmeldung seine Installation-ID. Ist die Installation noch an die technische Bootstrap-Lizenz gebunden und besitzt der Kunde eine aktive Lizenz mit freiem Installationsplatz, bindet der Lizenzserver die Installation automatisch an diese Kundenlizenz.

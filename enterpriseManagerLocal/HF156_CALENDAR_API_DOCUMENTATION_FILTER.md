# HF156 – Calendar API-Dokumentation aktualisiert

Die Calendar-API-Dokumentation wurde auf den HF155-Runtime-Stand angehoben. Dokumentiert sind jetzt insbesondere `TinyCalendar.render(filterObjekt)`, `render(null)` als ungefilterter Zustand, `getFilter()`, alle Filteroperatoren, filterbare DataForm-Felder über `filter_data` sowie personenbezogene Blockierungen. Die Dokumentation und die neuen JavaScript-Einzelbeispiele liegen sowohl im produktinternen Calendar-Paket als auch im Standalone-Runtime-Template.

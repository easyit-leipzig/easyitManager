HF109 – DATABASE BOOTSTRAP TEST REPORT
======================================

Ziel
----
Eine fehlende Lizenzserver-Datenbank easyit_license darf bei einer frischen lokalen Installation nicht mehr zu PDO #1049 / Unknown database führen.

Implementiert
-------------
- MySQL/MariaDB: Fehler 1049 / "Unknown database" wird erkannt.
- Verbindung wird einmal ohne dbname aufgebaut.
- Die konfigurierte Datenbank wird mit CREATE DATABASE IF NOT EXISTS erzeugt.
- MySQL/MariaDB-Datenbank wird mit utf8mb4 / utf8mb4_unicode_ci angelegt.
- Anschließend wird die normale Verbindung erneut aufgebaut.
- Die vorhandene MigrationRunner-Logik erzeugt bzw. aktualisiert die Tabellen.
- PostgreSQL: fehlende konfigurierte Datenbank wird analog über die Maintenance-DB postgres erzeugt.
- Bestehende Datenbanken werden niemals gelöscht oder neu erstellt.
- Fehlt CREATE-DATABASE-Berechtigung, wird ein verständlicher 503-Hinweis statt des ungefangenen Admin-PDO-Fatal-Errors ausgegeben.
- HF108-Lizenzerweiterung und HF106-Key-Bootstrap bleiben im kumulativen Update enthalten.

Hinweis zum Laufzeittest
------------------------
Die Build-Umgebung besitzt keinen laufenden lokalen XAMPP/MySQL-Server. Der reale #1049 -> CREATE DATABASE -> Reconnect-Pfad wurde deshalb statisch und syntaktisch geprüft, nicht gegen die MySQL-Instanz des Anwenders ausgeführt.
